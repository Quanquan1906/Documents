tự tạo service

Tạo mới project với nestjs: nest new <project_name>(monolithic) tao ra thang chính (ví dụ fast=food-services là thằng cha)

Tạo từng service: nest generate app <service_name> (microservice)

muốn run service nào ghi tên nó ra (npm run start fast-food-services)

nest g [moudule, service, controller] directory/path

"docker compose up": kéo hết tất cả service database chạy cùng lúc
